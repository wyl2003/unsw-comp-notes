反向传播：网络到底怎么学

这是整门课的计算核心。一句话：损失对某个权重的导数 = 「这个权重下游的误差」×「它上游的输入」。 考试几乎一定有一道「手算一次前向 + 反向 + 更新」的大题。掌握三件事就不会错： 链式法则、每个节点的局部导数、更新要减不要加。

考试怎么考
给网络结构、权重、输入、目标、学习率，求所有偏导并写出更新后的权重；或只问某个权重的梯度。
你需要先会
链式法则、偏导、sigmoid/tanh/ReLU 的导数（上一章那张表）。

3.1问题：输出错了，该怪哪个权重？

一个网络有几万个权重，输出错了，你想知道「把 $w_{11}$ 调大一点点，损失会变大还是变小、变多少」。 这个量就是偏导 $\partial E/\partial w_{11}$。有了它，更新就只是往反方向走一小步：

梯度下降（gradient descent）
$$w \leftarrow w-\eta\frac{\partial E}{\partial w}$$

问题是：$w_{11}$ 藏在网络深处，中间隔了好几层函数。直接求导要展开成巨大的表达式。 链式法则（chain rule）告诉我们：可以一段一段地乘起来，从输出往回算 —— 这就是反向传播。

$$\frac{\partial E}{\partial w}=\frac{\partial E}{\partial y}\cdot\frac{\partial y}{\partial s}\cdot\frac{\partial s}{\partial w}$$

三段各管一件事：下游有多错（$\partial E/\partial y$）、激活函数把误差放大还是缩小（$f'(s)$）、输入有多大（$\partial s/\partial w=x$）。

为什么叫「反向」 因为 $\partial E/\partial y$ 依赖下一层的误差，而下一层的误差又依赖再下一层……所以必须从输出层开始，倒着算。 倒着算还有个好处：同一条路径上的中间结果可以复用，一次反向传播就能拿到所有权重的梯度（复杂度与前向同阶）。

3.2两个公式，覆盖所有手算题

把「误差信号」定义为损失对预激活的导数，记作 $d_j$：

定义
$$d_j=\frac{\partial E}{\partial s_j}$$
反向传播（对隐藏层 $j$）
$$d_j=f'(s_j)\sum_{k} d_k\,w_{kj}$$
权重与偏置的梯度
$$\frac{\partial E}{\partial w_{ji}}=d_j\,y_i,\qquad \frac{\partial E}{\partial b_j}=d_j$$
逐项解释
$f'(s_j)$本单元激活函数的导数，用预激活 $s_j$ 算（ReLU 特别容易在这里错）。
$\sum_k d_k w_{kj}$所有下游单元把误差「按连接强度加权」传回来。这就是为什么叫 back-propagation。
$y_i$本单元的输入（上一层的输出）。梯度 = 误差 × 输入。

输出层是特例，$d_k$ 直接由损失函数给出：

输出层配置$d_k$记忆
线性输出 + 平方误差$z_k-t_k$「预测减目标」
sigmoid + 二元交叉熵$y_k-t_k$sigmoid 的导数被约掉了
softmax + 交叉熵$y_k-t_k$同上，第 7 章证明
这三个「正好是预测减目标」不是巧合 它们是故意配对的：损失函数选得对，输出层的梯度就最简、最不容易饱和。这就是第 7 章「为什么分类要用交叉熵」的答案。

dead ReLU 如果某个隐藏单元的 $s\lt 0$，它的导数是 0，于是 $d_j=0$，于是与它相连的所有权重梯度都是 0 —— 这个单元这一步完全不学。若它长期为负，就永远学不回来，称为 dead ReLU。下一节的例题里就有这个现象。

3.4梯度下降：走多快、往哪走、怎么不走歪

有了梯度，最朴素的更新就是「往负梯度方向走一步」。步长由学习率 $\eta$ 控制，这一件事就能决定训练成败。

LAB 04
学习率大了会发生什么
拖 η 再按自动
把 $\eta$ 拖到 2 以上：点会在谷底两侧来回跳，甚至越跳越远（发散）。$\eta$ 太小则要很多步才到。 结论：$\eta$ 是「稳定」与「速度」的权衡。

实际训练里，人们用几个技巧让「走」更稳。考试常让你写出更新式并解释作用：

动量（momentum）
$$v \leftarrow \beta v-\eta\frac{\partial E}{\partial w},\qquad w\leftarrow w+v$$
权重衰减 / L2 正则
$$E_{\text{total}}=E+\frac{\lambda}{2}\lVert w\rVert^2\quad\Longrightarrow\quad w\leftarrow w-\eta\left(\frac{\partial E}{\partial w}+\lambda w\right)$$
技巧解决什么一句话
动量震荡、峡谷地形累积历史梯度，像小球滚下山有惯性
权重衰减权重过大、过拟合每步都往 0 拉一点，等价于 L2 正则
小批量（mini-batch）计算量、噪声用一小批样本估计梯度，噪声反而帮助逃离坏点
学习率衰减后期震荡先大后小，靠近最优解时细调

练习

易练习 1 · 单输出单元的梯度

$z=0.8$，$t=1$，$E=\tfrac12(z-t)^2$，输入 $y=2$。求 $dz$ 与 $\partial E/\partial v$。

$dz=z-t=-0.2$；$\partial E/\partial v=dz\cdot y=-0.4$。

更新（$\eta=0.5$）：$v\leftarrow v+0.2$，输出会朝 1 靠近。

练习 2换激活函数重算

把例题 2 的隐藏层从 ReLU 换成 tanh，只重算 $y_1,y_2,dy_1,du_1,du_2$（4 位小数）。

$y_1=\tanh(-0.37)=-0.3540$，$y_2=\tanh(1.14)=0.8144$。

$z_1=0.3(-0.3540)-0.6(0.8144)-0.3=-0.8948$，$z_2=-0.4(-0.3540)-0.8(0.8144)+0.2=-0.3099$。

$dz=(-1.8948,\,-0.3099)$；$dy_1=dz_1(0.3)+dz_2(-0.4)=-0.4445$；$dy_2=dz_1(-0.6)+dz_2(-0.8)=1.3849$。

$du_1=dy_1(1-y_1^2)=-0.3888$；$du_2=dy_2(1-y_2^2)=0.4663$。

$du=(-0.3888,\;0.4663)$

对比 ReLU 版的 $du_1=0$：换成 tanh 后第一个单元「活过来了」，也开始学习。这就是激活函数选择的实际影响。

练习 3两个样本的批梯度

同一个 ReLU 网络，样本 2 的 $u_1=0.6,\;y_1=0.6,\;z_1=0.9,\;t_1=0$（只看输出 1）。求 $w_{11}$ 在两个样本上的总梯度，并说明 mini-batch 与在线更新的差别。

样本 1：$du_1=0$（dead ReLU），贡献 $0$。

样本 2：$dz_1=0.9-0=0.9$，$dy_1=dz_1v_{11}=0.27$，$du_1=0.27$（$u_1\gt 0$ 导数为 1），$\partial E/\partial w_{11}=du_1x_1=0.27(0.5)=0.135$。

总梯度 $0.135$（若取平均则 $0.0675$）

差别：在线（SGD）每来一个样本就更新一次，噪声大但反应快；mini-batch 把梯度求和/平均后再更新一次，方向更准、可用矩阵运算加速。 批大小是「方差」与「速度」的权衡。

变种题

变种 1交叉熵 + sigmoid 输出

二分类，输出 sigmoid，损失 $E=-[t\ln y+(1-t)\ln(1-y)]$。证明 $dz=y-t$，并解释为什么这比「sigmoid + 平方误差」好。

$\dfrac{\partial E}{\partial y}=-\dfrac{t}{y}+\dfrac{1-t}{1-y}$，又 $y'=y(1-y)$，故

$dz=\dfrac{\partial E}{\partial y}y(1-y)=-[t(1-y)-(1-t)y]=y-t$。

$dz=y-t$

平方误差配 sigmoid 时，$dz=(y-t)y(1-y)$：当输出严重错误（$y$ 接近 0 或 1）时 $y(1-y)\to0$，梯度反而消失。 交叉熵把它约掉了，错误越大梯度越大，学得更快。

变种 2动量 + 权重衰减

写出带动量与 L2 权重衰减的更新式，并说明两者各自解决什么问题。

$v\leftarrow\beta v-\eta\left(\dfrac{\partial E}{\partial w}+\lambda w\right)$，$w\leftarrow w+v$。

动量（$\beta\approx0.9$）累积历史方向，抑制来回震荡、加速沿峡谷前进；权重衰减（$\lambda w$）每步把权重往 0 拉， 限制模型复杂度、缓解过拟合。

注意：两者都会改变「有效学习率」，$\lambda$ 太大模型会欠拟合。
