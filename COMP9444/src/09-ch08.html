8.1卷积 = 拿一个小模板在图上滑动

一个 $3\times3$ 的核（filter / kernel）盖在图像的一小块上，逐元素相乘再求和，得到一个数；然后按步长（stride）挪到下一块。 滑完一遍就得到一张特征图（feature map）。

二维离散卷积（深度学习里实际是互相关）
$$y_{ij}=\sum_{m=0}^{M-1}\sum_{n=0}^{N-1}w_{mn}\,x_{i\cdot s+m,\;j\cdot s+n}+b$$
$M\times N$核的高与宽（如 $3\times3$、$8\times8$）。
$s$步长 stride：每次挪几格。$s\gt 1$ 会降采样。
$L$输入通道数（灰度图 $L=1$，RGB $L=3$，中间层常见 16/32/256）。
$b$每个核一个 bias，所以「每个 filter 的权重数」= $1+MNL$。
两个关键设计 局部连接：每个输出只依赖输入的 $M\times N$ 区域 —— 图像里邻近像素才相关。 权重共享：同一个核在整张图上复用 —— 一只猫出现在左上角还是右下角，检测它的模板应该一样。 这两条把参数量从「像素数 × 单元数」降到「核大小 × 通道数」，还自带平移等变性。
术语澄清 数学上的卷积会把核翻转 180°，深度学习框架（以及本课程）用的其实是互相关（不翻转）。 答题时写 “cross-correlation, as implemented in deep learning frameworks” 即可，不影响任何计算。

8.2三个公式，覆盖所有计算题

输出边长（无 padding 或 padding P）
$$J'=\left\lfloor\frac{J+2P-M}{s}\right\rfloor+1$$
神经元数 / 连接数 / 独立参数
$$\text{neurons}=J'\times K'\times L',\qquad \text{connections}=\text{neurons}\times(1+MNL)$$ $$\text{parameters}=L'\times(1+MNL)$$

注意区分三个容易混的量：

量含义为什么考
每个 filter 的权重$1+MNL$含 bias，容易漏
连接数 connections神经元数 × 每个神经元的输入数衡量计算量，不是参数量
独立参数$L'\times(1+MNL)$因为权重共享，等于「filter 数 × 每个 filter 的权重」
最常见的错 把 connections 当成 parameters。卷积层里同一种核被复用了几千次，参数只有一份，连接却有几千份 —— 这正是卷积「省参数」的全部秘密。

8.3池化与感受野

池化（pooling）没有参数，只做降采样：$2\times2$ 最大池化把每个 $2\times2$ 块压成最大值，尺寸减半。

类型做什么作用
max pooling取块内最大值保留最强响应，对小幅平移不敏感
average pooling取平均更平滑，常用在全局池化

感受野（receptive field）是一个输出单元在原始输入上「看到」的区域。堆两个 $3\times3$ 卷积（stride 1）的感受野是 $5\times5$， 三个是 $7\times7$ —— 这就是「用多层小核替代一个大核」的动机：参数更少（$3\times9=27$ vs $49$），非线性更多。

$$R_{\text{out}}=R_{\text{in}}+(M-1)\times\prod_{\text{前面各层的 stride}}s_i$$

8.4课内原题：Mnih 的 DQN 网络逐层算

网络描述：输入 $84\times84\times4$（四帧灰度图堆叠）；第一层 16 个 $8\times8$ 卷积、stride 4；第二层 32 个 $4\times4$ 卷积、stride 2； 然后 256 个全连接 ReLU；输出 18 个动作。无 padding。

逐步验算（考试就按这个顺序写）：

卷积 1
$1+8\times8\times4=257$；输出 $1+(84-8)/4=20$；神经元 $20^2\times16=6400$；连接 $6400\times257=1\,644\,800$；参数 $16\times257=4112$。
卷积 2
$1+4\times4\times16=257$；输出 $1+(20-4)/2=9$；神经元 $9^2\times32=2592$；连接 $2592\times257=666\,144$；参数 $32\times257=8224$。
全连接
每个神经元接收 2592 个输入 + 1 个 bias = 2593；256 个神经元 → 连接 = 参数 = $256\times2593=663\,808$。
输出
$18\times(256+1)=4626$。
总计 $4112+8224+663808+4626=680\,770$ 个参数
观察 两个卷积层加起来只有 $12\,336$ 个参数，全连接层却有 $663\,808$ —— 卷积很省，全连接很贵。 这也是后来用全局平均池化替代大全连接层的原因。

8.5训练深网络的三个配件

权重初始化。反向传播时梯度方差近似按层数连乘（课件的式子）：

$$\mathrm{Var}\!\left[\frac{\partial}{\partial x}\right]\simeq\left(\prod_i G_i\,n_{(i+1)}\,\mathrm{Var}[w^{(i)}]\right)\mathrm{Var}\!\left[\frac{\partial}{\partial z}\right]$$

若每层的因子 $G_i n_{(i+1)}\mathrm{Var}[w^{(i)}]$ 都约等于 1，梯度方差就能保持稳定；否则指数级爆炸或消失。 Xavier 初始化取 $\mathrm{Var}(w)\approx 2/(n_{\text{in}}+n_{\text{out}})$，He 初始化取 $2/n_{\text{in}}$（配 ReLU）。

批归一化（batch normalisation）。对一个 mini-batch 内每个通道的激活做标准化，再学一个缩放和平移：

$$\hat x_k=\frac{x_k-\mathrm{Mean}[x_k]}{\sqrt{\mathrm{Var}[x_k]}},\qquad y_k=\beta_k+\gamma_k\hat x_k$$

$\beta,\gamma$ 是可学习参数（每个通道一组），由反向传播更新。好处：允许更大学习率、对初始化不敏感、有轻微正则效果。 推理时用训练阶段累积的滑动平均均值/方差。

残差 vs 稠密连接。

ResNetDenseNet
连接方式跨过一对相邻层加一条 shortcut：$y=x+F(x)$块内每一层都连接到之前所有层：$x_l=[x_0,\dots,x_{l-1}]$
学什么学「残差」$F(x)$，即对前层输出的修正/补充细节每层只加一小撮新特征（growth rate），特征复用
梯度shortcut 提供恒等通路，缓解梯度消失稠密短路让梯度直通早期层
代价显存中等特征图拼接，显存/带宽更大
一句话答案 “A residual network adds skip connections that bypass each pair of consecutive layers, so those layers learn a residual correction; a dense network concatenates the outputs of all preceding layers within a block.”

例题 2权重初始化（Tutorial 7 Q2）

简述梯度消失/爆炸问题，以及权重初始化如何缓解。

反向传播时梯度是各层局部导数的连乘。若每层因子平均小于 1，梯度随深度指数衰减（消失）；大于 1 则指数增长（爆炸）。

初始化时让每层的 $\mathrm{Var}[w^{(i)}]$ 满足 $G_i\,n_{(i+1)}\mathrm{Var}[w^{(i)}]\approx1$， 则连乘的期望为 1，梯度方差在层间保持稳定。Xavier 用 $2/(n_{\text{in}}+n_{\text{out}})$，He 用 $2/n_{\text{in}}$（配 ReLU）。

英文写法

“If weights are initialised so that $G_i n_{(i+1)}\mathrm{Var}[w^{(i)}]\approx 1$ for every layer, the variance of the gradients is preserved across layers instead of decaying or exploding exponentially.”

$32\times32$ 输入，$5\times5$ 核，stride 1，padding 2。输出多大？参数量（16 个 filter，输入 3 通道）？

练习 2哪种更省参数

$56\times56\times64$ 的特征图，分别用「一个 $7\times7$ 卷积（64 输出）」和「三个 $3\times3$ 卷积（各 64 输出）」处理，比较参数量与感受野。

单个 $7\times7$：$64\times(1+7\times7\times64)=64\times3137=200\,768$。

三个 $3\times3$：每个 $64\times(1+9\times64)=64\times577=36\,928$，三个共 $110\,784$。

感受野都是 $7\times7$。所以「小核堆叠」省约 45% 参数，还多了两次非线性。

200 768 vs 110 784

练习 3尺寸公式反推

$224\times224$ 输入，$7\times7$ 核，stride 4。(a) 不加 padding，输出多大？(b) 要得到 $56\times56$ 至少需要多少 padding？(c) stride 2 时要得到 $112\times112$ 需要多少 padding？

(a) $\lfloor(224-7)/4\rfloor+1=\lfloor217/4\rfloor+1=54+1=55$（因为 $217/4=54.25$，向下取整是 54）。

(b) 要求 $\lfloor(217+2P)/4\rfloor=55$，即 $220\le217+2P\lt224$，解得 $1.5\leP\lt3.5$，所以 $P=2$ 或 $P=3$ 都行（$221/4=55.25$、$223/4=55.75$ 都取整到 55）。

(c) 要求 $\lfloor(217+2P)/2\rfloor=111$，即 $222\le217+2P\lt224$，解得 $2.5\leP\lt3.5$，只有 $P=3$（$223/2=111.5$）。

55；$P=2$（或 3）；$P=3$

要点：向下取整让 padding 常有一小段「都行」的区间，答案给一个可行值即可，但代入过程要写清楚。

约 1.8 亿 vs 4112

变种 2BatchNorm 放在激活前还是后

「conv → BN → ReLU」与「conv → ReLU → BN」有什么差别？

前者是标准做法：先归一化预激活，再让 ReLU 在零附近工作，避免大量单元落入负半轴死掉。

后者归一化的是 ReLU 之后的非负分布，均值不为 0，效果较差；但某些残差网络会用 pre-activation 变体（BN→ReLU→conv）。
