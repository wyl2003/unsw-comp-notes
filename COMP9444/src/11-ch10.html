强化学习与 Q-Learning

前面所有章节都是「给数据、学映射」。强化学习不同：没有正确答案，只有奖励，而且现在的动作会改变未来能看到什么。 这一章用课内那个只有 2 个状态、2 个动作的小世界，把 MDP、值函数、贝尔曼方程、Q-learning 和「为什么要探索」一次讲完 —— 这题几乎年年考，而且数字好算。

10.1把「打游戏」写成数学

一个马尔可夫决策过程（MDP）由五件事组成：

$S$状态集合（state）。这里 $S=\{S_1,S_2\}$。
$A$动作集合（action）。这里 $A=\{a_1,a_2\}$。
$\delta(s,a)$转移函数：在 $s$ 做 $a$ 会到哪个状态（随机情形是概率分布 $P(s'\mid s,a)$）。
$r(s,a)$即时奖励（reward）。
$\gamma$折扣因子（discount factor），$0\le\gamma\lt 1$：未来的奖励要打折。

智能体想要最大化的不是某一步的奖励，而是回报（return）：

折扣回报
$$G_t=r_{t+1}+\gamma r_{t+2}+\gamma^2r_{t+3}+\cdots=\sum_{k=0}^{\infty}\gamma^{k}r_{t+k+1}$$
为什么要折扣 ① 数学上保证无穷和收敛（$\gamma\lt 1$）；② 语义上「现在的 1 块比以后的 1 块值钱」； ③ 让策略偏向更快拿到奖励。$\gamma=0$ 变成只看眼前，$\gamma\to1$ 变得极端有耐心。

10.2值函数与贝尔曼方程

在状态 $s$ 开始、之后一直按策略 $\pi$ 行动，期望能拿到的折扣回报就是状态值函数：

Bellman expectation equation
$$V^{\pi}(s)=\sum_{a}\pi(a\mid s)\left[r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^{\pi}(s')\right]$$
最优值函数
$$V^{*}(s)=\max_{a}\left[r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^{*}(s')\right]$$

确定性环境下把期望去掉，就是课内用的那两条方程：

$$V(S_1)=-2+\gamma V(S_2),\qquad V(S_2)=7+\gamma V(S_1)$$

两个未知数、两个方程，代入消元即可。这类「联立方程」是本章手算题的标准形态。

Q 函数 $Q(s,a)=r(s,a)+\gamma V^{*}(\delta(s,a))$ 是「在 $s$ 先做 $a$、之后最优」的价值。 有了 $Q$，最优策略就是每个状态取 $\arg\max_a Q(s,a)$ —— 这也是 Q-learning 直接学 $Q$ 的原因。

10.4γ 从 0 变到 1，最优策略会换三次

四个确定性策略 $\pi_{ij}$ 表示「$S_1\to a_i$，$S_2\to a_j$」。分别解方程：

策略$V(S_1)$$V(S_2)$
$\pi_{11}$（都选 $a_1$）$\dfrac{1}{1-\gamma}$$7+\gamma V(S_1)$
$\pi_{12}$$\dfrac{1}{1-\gamma}$$\dfrac{3}{1-\gamma}$
$\pi_{21}$（都去 $S_2$ 吃 +7）$\dfrac{-2+7\gamma}{1-\gamma^2}$$7+\gamma V(S_1)$
$\pi_{22}$（都留在 $S_2$）$-2+\dfrac{3\gamma}{1-\gamma}$$\dfrac{3}{1-\gamma}$

比较 $V(S_1)$ 的大小，得到三条分界线：

$$\pi_{11}\succ\pi_{21}\iff\gamma\lt 0.5,\qquad \pi_{21}\succ\pi_{22}\iff\gamma\lt 0.8$$
$\gamma\lt 0.5$：$\pi_{11}$；$0.5\lt \gamma\lt 0.8$：$\pi_{21}$；$\gamma\gt 0.8$：$\pi_{22}$；$\pi_{12}$ 永远不是最优

直觉：$\gamma$ 小 → 只顾眼前，$S_1$ 的 +1 最好；$\gamma$ 大 → 愿意忍受 −2 去换 $S_2$ 的 +7； 再大 → 连 $S_1$ 都不回去了，永远待在 $S_2$ 里拿 +3（因为回去要先亏 −2，而未来折现后不值）。

易错 $\pi_{12}$ 与 $\pi_{11}$ 在 $S_1$ 上完全一样（都选 $a_1$），所以 $V(S_1)$ 相同，但 $S_2$ 上更差 —— 它被 $\pi_{11}$ 严格支配， 永远不会最优。答题时点出「dominated」会加分。

10.5Q-learning：不用模型，边玩边学

现实中我们往往不知道 $\delta$ 和 $r$，只能「走一步看一步」。Q-learning 用采样到的 $(s,a,r,s')$ 直接更新：

Q-learning 更新
$$Q(s,a)\leftarrow Q(s,a)+\alpha\left[\underbrace{r+\gamma\max_{b}Q(s',b)}_{\text{TD target}}-Q(s,a)\right]$$

方括号里叫时序差分误差（TD error）。$\alpha=1$ 且环境确定性时，退化成课件的简洁形式：

$$Q(s,a)\leftarrow r(s,a)+\gamma\max_b Q(\delta(s,a),b)$$

课内要求追踪前几步（$\gamma=0.7$，$\alpha=1$，初值全 0，从 $S_1$ 出发）：

步状态动作计算新 Q下一状态
1$S_1$$a_1$$1+0.7\max Q(S_1,\cdot)=1$$Q(S_1,a_1)=1$$S_1$
2$S_1$$a_2$（强制探索）$-2+0.7\max Q(S_2,\cdot)=-2$$Q(S_1,a_2)=-2$$S_2$
3$S_2$$a_2$$3+0.7\max Q(S_2,\cdot)=3$$Q(S_2,a_2)=3$$S_2$
4$S_2$$a_1$$7+0.7\max Q(S_1,\cdot)=7.7$$Q(S_2,a_1)=7.7$$S_1$
5$S_1$$a_1$$1+0.7\max(1,-2)=1.7$$Q(S_1,a_1)=1.7$$S_1$
6$S_1$$a_2$$-2+0.7\times7.7=3.39$$Q(S_1,a_2)=3.39$$S_2$

继续下去会收敛到 $4.98/5.69/10.98/10.69$。注意每一步的 $\max$ 用的是更新后的表。

为什么必须探索 若总是贪心选当前最大的 $Q$，第 1 步之后 $Q(S_1,a_1)=1\gt Q(S_1,a_2)=0$，智能体会永远选 $a_1$， $Q(S_1,a_2)$ 永远是 0，永远发现不了「去 $S_2$ 更赚」。这叫过早收敛到次优策略。 所以要用 $\varepsilon$-greedy（以 $\varepsilon$ 概率随机）或 softmax 采样来保证每个 $(s,a)$ 都被访问到。

收敛条件（ tabular 情形）：每个状态-动作对被无限次访问，且学习率满足 $\sum\alpha_t=\infty,\ \sum\alpha_t^2\lt \infty$。

10.6从 Q 表到 DQN

状态一多（比如像素输入），表格存不下。DQN 用神经网络 $Q(s,a;\theta)$ 近似，并加了两个稳定训练的技巧：

  • 经验回放（experience replay）：把 $(s,a,r,s')$ 存进缓冲区，随机抽样训练，打破时间相关性。
  • 目标网络（target network）：用一个延迟更新的副本算 TD target，避免「自己追自己」的震荡。
$$L(\theta)=\mathbb E_{(s,a,r,s')}\left[\left(r+\gamma\max_{b}Q(s',b;\theta^-)-Q(s,a;\theta)\right)^2\right]$$

这个网络的输入就是第 8 章那道题里的 $84\times84\times4$ 图像，输出 18 个动作的 Q 值 —— 两章在这里接上了。

例题 2Q-learning 的前几步与探索（Tutorial 8 Q1(e)）

$\gamma=0.7$、$\alpha=1$、$Q$ 全 0、从 $S_1$ 开始。追踪前几步，并解释为什么必须强制探索。

表格见 10.5 节（$1\to-2\to3\to7.7\to1.7\to3.39$）。

不探索的后果：一旦 $Q(S_1,a_1)$ 变成正数，贪心永远选 $a_1$，$Q(S_1,a_2)$ 保持 0， 永远学不到它真正的价值 5.69，策略卡在次优。

英文写法

“Without forced exploration the agent always exploits the first action that receives a positive value, so the alternative action is never sampled and its Q-value never converges to the true value.”

练习 3推出 0.5 与 0.8 两条分界线

证明：$\pi_{11}$ 与 $\pi_{21}$ 在 $\gamma=0.5$ 处相等；$\pi_{21}$ 与 $\pi_{22}$ 在 $\gamma=0.8$ 处相等。

第一组：$\dfrac{1}{1-\gamma}=\dfrac{-2+7\gamma}{1-\gamma^2}=\dfrac{-2+7\gamma}{(1-\gamma)(1+\gamma)}$， 两边乘 $(1-\gamma)$ 得 $1=\dfrac{-2+7\gamma}{1+\gamma}\Rightarrow1+\gamma=-2+7\gamma\Rightarrow\gamma=0.5$。

变种题

变种 1把奖励 −2 改成 0

若 $r(S_1,a_2)=0$，$\gamma=0.7$ 时最优策略还是 $(a_2,a_1)$ 吗？

假设 $\pi_{21}$：$V(S_1)=0+0.7V(S_2)$，$V(S_2)=7+0.7V(S_1)$ ⇒ $V(S_1)=0.7(7+0.7V_1)$ ⇒ $0.51V_1=4.9$ ⇒ $V_1=9.608$，$V_2=13.725$。

仍选 $a_2$（$Q(S_1,a_1)=1+0.7(9.608)=7.726\lt 9.608$）。策略不变，值变大。

变种 2随机转移

若在 $S_1$ 选 $a_1$ 时以 0.8 概率留在 $S_1$、0.2 概率去 $S_2$，方程怎么变？

$Q(S_1,a_1)=1+\gamma[0.8V(S_1)+0.2V(S_2)]$，其余动作不变（确定性）。

其余步骤相同，只是多了一层期望。这就是「带模型的策略评估」（policy evaluation）。
